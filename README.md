# NotaNFC+ Digital Studio

Site institucional e portfólio comercial da NotaNFC+.

## Stack
- Next.js 15 (App Router)
- React 19 + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
npm start
```

## Antes de publicar
- Substituir o número de WhatsApp de demonstração em `app/page.tsx`.
- Confirmar autorização e disponibilidade das imagens usadas.
- Trocar os projetos ilustrativos por cases aprovados e links reais.
- Atualizar domínio e metadados em `app/layout.tsx`.
- Executar `npm run build` e testar em dispositivos reais.

O portfólio diferencia conceitos visuais de cases publicados: não apresentar projetos de demonstração como resultados ou clientes confirmados.
